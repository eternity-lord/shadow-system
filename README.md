# Shadow System (سیستم سایه)

یک اپلیکیشن اندروید **کاملاً آفلاین، فارسی و راست‌به‌چپ** برای مدیریت زندگی به سبک بازی‌های نقش‌آفرینی
(الهام از Solo Leveling) همراه با مدیریت مالی شخصی. طراحی‌شده برای افراد با ADHD.

## ویژگی‌ها
- **امروز**: امتیاز روزانه، سطح و رتبه، حال روز، مأموریت‌های اصلی، صندوق ورودی (یادداشت سریع) و باس هفتگی
- **مأموریت‌ها**: مراحل کوچک با ۵ ثانیه بازگشت، «خیلی سخته» (کوچک‌تر کن) و «بعداً»
- **سیاه‌چال**: تایمر در سرویس پیش‌زمینه (با اعلان)، توقف، جان هیولا، غنیمت با نشان نادر و یادداشت ژورنال، صدای محیط و لرزش اختیاری
- **سربازان سایه**: ۱۲ سرباز، احضار بعد از ۷ روز فعال، تجربه از مأموریت‌های مرتبط، حالت‌های بیدار/خسته/خواب، تکامل ۵ مرحله‌ای با کات‌سین، لایه‌ی حکمت، تغییر نام
- **شکارچی**: آواتار رتبه‌ای، کلاس هفتگی، نمودار صفات (Canvas)، عنوان‌ها، دستاوردها، فروشگاه ظاهر با طلا
- **پول**: هزینه و درآمد (به تومان)، دسته‌بندی، بودجه با هشدار ۸۰٪، قوانین تکرارشونده، هدف پس‌انداز، بدهی و قسط، گزارش و نمودار، جستجو، خروجی CSV، پشتیبان رمزنگاری‌شده
- **امنیت**: قفل PIN و بیومتریک، FLAG_SECURE، پنهان‌سازی مبالغ
- تقویم جلالی با تبدیل میلادی و نمایش ارقام فارسی

## ساختار
- `core/` منطق خالص (تقویم جلالی، فرمول‌های بازی، قالب مأموریت‌ها، متن‌ها)
- `data/db` اتاق (Room)، `data/repo` مخازن
- `ui/vm` ViewModelها، `ui/screens` صفحات، `ui/components` اجزای کوچک، `ui/nav` ناوبری
- `di/AppContainer` تزریق وابستگی دستی

## ساخت و تست
```bash
./gradlew assembleDebug testDebugUnitTest
```
CI در `.github/workflows/android.yml` همین دستور را اجرا می‌کند و APK دیباگ را آرتیفکت می‌گذارد.
